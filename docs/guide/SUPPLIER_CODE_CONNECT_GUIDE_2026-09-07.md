# 운영자 가이드 — 발행상품에 "도매꾹 코드 연결"하기 (재고추적 켜기)

> 대상: 대표님(비개발자). 발행된 6개 상품 중 5개가 도매꾹 원본코드 미연결
> 상태라 재고추적이 꺼져 있음. 이걸 켜면 품절알림·자동처분·디스코드
> 재고알림·웹앱 알림센터가 그 상품에도 작동함.

## 왜 자동으로 안 되나 (2026-09-07 실측)
5개 전부 "네이버에서 가져온 상품"이라 도매꾹 크롤이력과 이름이 안 맞아
자동매칭 실패(matched:false 5/5 확인). "이 상품이 도매꾹 몇 번 상품인가"는
대표님만 아시는 정보라 Claude가 대신 못 함(임의번호 넣으면 엉뚱한 상품
재고를 추적 = 더 위험).

## 준비물
각 상품의 **도매꾹 상품번호**. 도매꾹에서 그 상품 페이지 URL의 숫자.
예: domeggook.com/12345678 → 코드는 12345678.
(접이식트렁크는 이미 43595104로 연결됨 = 참고 예시)

## 단계 (5개 상품 각각 반복)
1. 앱 좌측 메뉴 **"꽃밭 돌보기"** 클릭 → 발행상품 목록.
2. 빨간 **"재연동 필요"** 배지 붙은 상품(듀얼무선가습기·저소음물멍·
   LED차량가습기·슬림불멍가습기·플라티코화분) 중 하나를 클릭.
3. 우측에 상품 상세 패널(드로어)이 열림.
4. 노란 박스 **"재고추적 연결 필요"** 안의 갈색 버튼
   **"🔗 도매꾹 코드 연결"** 클릭.
5. (자동매칭 시도 후 실패하면) 입력칸이 나타남 → 그 상품의 도매꾹
   상품번호(숫자) 입력 → 확인.
6. 성공하면 **"재고추적 시작됨 · 현재고 N개"** 표시 + 배지 사라짐.
   (즉시 재고를 가져옴 — 24시간 안 기다려도 됨)
7. 나머지 4개 상품에 2~6 반복.

## 확인
5개 다 하면 "꽃밭 돌보기"에서 "재연동 필요" 배지가 모두 사라짐.
이후 매일 재고가 자동 추적되고, 품절/가격변동 시 디스코드+웹앱 알림.

## 만약 도매꾹 상품번호를 모르겠으면
그 상품을 도매꾹에서 판매자명/상품명으로 검색 → 맞는 상품 페이지 URL의
숫자가 코드. 못 찾으면 "이 상품은 도매꾹에서 내려간 것"일 수 있음(그러면
재고추적 대신 대체소싱 대상). 헷갈리면 상품명 알려주시면 함께 확인.
