## 1. ★★ 트랙B — 소싱 상세 드로어 UI (커밋 `a4efb79`, 브라우저 실사용 검증 완료)

`/growth` 소싱 추천 카드가 **요약**(빠른 스캔)이라면, 드로어는 **심화** — 발굴한 키워드의 전체 정보를 한 화면에서 보고 바로 소싱을 시작한다. 프리미엄 SaaS 우측 슬라이드 패턴.

**구성**:
- 카드 확장 상세에 "상세 보기 · 소싱 시작" 버튼 → 우측 드로어(min(460px,92vw))
- 헤더: 키워드 + 블루오션 점수 + 경쟁 배지 + 닫기(X)
- 핵심지표 그리드: 월 검색량 · 카테고리 · 실측 도매 공급가
- 꼬띠의 소싱 조언: AI 인사이트 **전문**(카드는 축약)
- 도매 매칭 **전체 목록**: priceOutlier("다른 상품일 수 있어요")·accessoryRisk("부속품일 수 있어요") 경고를 카드보다 자세히 명시, 항목별 보러가기
- 도매매/도매꾹 직접 검색 버튼
- 푸터 주 액션: "이 키워드로 소싱 시작"

**★ 소싱 시작 배선 — 기존 경로 재사용(#62)**: 새 파라미터(sourcingKeyword)를 만들지 않고, `/products/new`가 이미 받는 `?prefillName=`(page.tsx:1296 setProductName)으로 연결. 발굴→등록 사이 키워드 재입력 0. 새 수신부 코드 불필요.

**★ 구현 중 JSX 구조 오류 발견·수정**: 드로어 트리거 버튼을 도매매칭 map 내부에 잘못 삽입 → 닫는 태그 5개 누락을 tsc로 즉시 발견, 확장 상세 블록 끝으로 재배치.

**브라우저 실사용 엔드투엔드 검증(로컬)**:
- 최신 스캔(db-full: 가습기·발마사지기·체중계·청소기·공기청정기)에서 드로어 열림 — 도매매칭 5건 전부 진짜 가습기 본품(청소솔 없음, 부속품 필터 효과 화면 확증)
- backdrop 클릭 → 정상 닫힘
- "소싱 시작" → `/products/new?prefillName=가습기` → 상품명 입력란 "가습기" 자동 프리필 확인(input value 실측)
