## 2. ★ 다음 세션이 반드시 알아야 할 것

### 2-1. "에이전트" 요청이 오면 먼저 계층부터 확정 (#321)
| 계층 | 24시간 자동 실행 |
|---|---|
| A. Claude Code 서브에이전트(`.claude/agents/`) | ❌ 세션 중에만 |
| B. Desktop MCP | ❌ 대화 중에만 |
| C. 앱 파이프라인(`src/lib/`+Cron) | ✅ |

운영자가 원하는 건 거의 항상 **C**. A·B로는 아침 8시 디스코드 발송이 **기술적으로 불가능**하다. MCP(B)의 올바른 활용은 "1회성 리서치로 시드 데이터셋 구축 → 앱(C)이 매일 사용"(예: 시즌 캘린더).

### 2-2. 병렬 진행 판단은 write set으로 (#322)
"주제가 다른가"가 아니라 "**수정 파일이 겹치는가**". 스케줄 보드에 각 작업의 write set과 PARALLEL-OK 표기됨.

### 2-3. 웹스크래핑 범위 — 정직한 한계
| 데이터 | 방법 | 자동화 |
|---|---|---|
| 트렌드·검색량·경쟁·도매상품 | 공식 API(DataLab·쇼핑검색·검색광고·도매꾹) | ✅ 구현됨 |
| 시즌 캘린더 | Desktop MCP 리서치(1회성) → 시드 데이터셋 | ⚠️ 반자동 |
| 임의 사이트 스크래핑 | — | ❌ **하지 않음**(ToS·차단 위험) |
