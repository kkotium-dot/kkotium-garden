## 1. 소싱봇 모바일 레이아웃 재설계 — 옵션1(필드 압축) 구현 완료 (커밋 `7907901`)

**사전 실측**: Discord 공식 문서·커뮤니티 가이드 웹서치로 확인 — embed는 클라이언트 렌더(desktop/mobile)에 따라 폭이 다르고, inline 필드도 화면폭에 따라 자동 세로 재배치됨. 이로써 설계문서 §3-2에서 세웠던 "옵션2(inline 3분할)는 리스크 있음" 가정이 사실로 확인됨 → 옵션1(필드 압축, inline 미사용)로 확정.

**구현 내용**:
- AI 코멘트를 상품별 필드에서 제거, `description`(상단 요약, `aiSummary`)에만 1회 노출 — 이전엔 5개 필드마다 반복돼 필드 하나가 5~6줄까지 길어짐(운영자 스크린샷 실측 근거)
- 상품별 필드를 "경쟁+검색량" 1줄 + "도매처+가격" 1줄, **총 2줄**로 압축(이전 5~6줄)
- 도매처 표시 2건→1건. 단 최저가가 이종상품 의심(`priceOutlier`)이면 그 다음 정상가로 자동 폴백(정상품 정보 손실 방지) — 전부 outlier면 최저가로 재폴백
- outlier 경고는 완전 생략하지 않고 축약형(`:warning:다른상품일수있음`)으로 유지 — 필드압축과 "이유를 알아야 한다"는 기존 운영자 요구 사이 균형

**실증 검증(로컬 dry-run)**: 상품별 필드 5~6줄→2줄 축소 확인. 캐리어(최저가 90원=outlier)는 정상가 990원으로 자동 폴백 확인. 캠핑테이블(최저가 1,090원=outlier)도 정상가 8,290원으로 폴백 확인. AI코멘트는 description에만 등장, 필드에서 완전 제거 확인.

**검증**: tsc 0 · build 0(grep error|failed 0건) · 로컬 dry-run 실증.

**미완료**: 프로덕션 배포 확인, 프로덕션 curl 재검증, 실제 Discord 재발송으로 모바일 최종 확인(발송은 운영자 승인 필요 — 이전 세션 실발송 1회 완료했으므로 재발송 여부는 운영자 판단).
