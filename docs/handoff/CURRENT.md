## 2. ★ 시스템 레벨 전수조사 — 다른 위젯 3개 안전 확인 완료

`grep`으로 `estimatedMargin|avgPrice|totalResults` 사용처 전수 확인 → 소싱 위젯 외 3개 파일(`MarketAnalysisCard.tsx`, `CompetitionMonitorWidget.tsx`, `MarketTrendWidget.tsx`) 발견. 코드 실측 + 프로덕션 브라우저 실측(`/market` 페이지) 결과:

- 전부 **방어적 조건부 렌더링**(`if(total===0 && avg===0) return null` 또는 `{s && ...}`)이 이미 있어 **거짓값 노출 없음** — 섹션이 조용히 안 보이거나 "0/2" 정직 표시만 됨.

**설계 문서**: `docs/design/SOURCING_DEEP_DIVE_WEBAPP_2026-08-04.md`

**핵심 설계 방향(3트랙)**:

- **트랙 B**: 심화 UI — 안1(상세 드로어, 권장·빠름) vs 안2(전용 아카이브 페이지, 트랙A 선행 필요)
- **트랙 C(대표님이 가장 강조)**: 실무 자동화 — "이 키워드로 소싱 시작" 원클릭(도매매칭 상품 정보를 씨앗심기 화면에 프리필), 낙점 상태 관리, 주간 요약

**부수 발견**: "스캔 시작" 버튼이 `discord:true`로 고정돼 있어 웹에서 눌러도 실제 Discord 알림이 나감 — 웹 스캔과 Discord 발송 분리 필요(트랙 B/C와 함께 처리 예정).

**구현 순서 제안**: 트랙A(DB확장) → daily 크론 저장로직 갱신 → 트랙B안1(드로어) → 트랙C-1(원클릭 소싱) → 스캔버튼 discord 분리 → 트랙C-2/3.
