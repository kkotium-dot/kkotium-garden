## 1. 문제 정의 (실측 근거)

도매매칭(도매처 전문검색) 결과에서 **키워드는 맞으나 카테고리가 완전히 다른 동음 상품**이 최저가로 섞이는 문제.

**2026-08-05 실측 사례** (아침 소싱봇 dry-run):
| 소싱 키워드 | 걸린 상품 | 문제 유형 |
|---|---|---|
| 청소기 | "진동 흡입 **귀**클리너/**귀**청소기" 2,600원 | 동음 카테고리 (진공청소기 ≠ 귀청소기) |
| 청소기 | "**어항** 자석 미니 청소기" 5,770원 | 동음 카테고리 (진공청소기 ≠ 수족관용품) |
| 청소기 | "하수구막힘 뚫어뻥 **스프링**청소기" 5,850원 | 동음 카테고리 |

이번 세션에 이미 **부속품·소모품 필터**(`accessoryRisk`)는 근본 구현 완료(커밋 975565f). 그러나 위 케이스는 부속품이 아니라 **"청소기"라는 단어를 공유하는 다른 종류의 본품**이라 신호어 사전으로 못 잡는다. 이건 별도 축의 문제.

---

## 2. 이번 리서치의 목표

**"소싱 키워드가 의도한 상품 카테고리와, 도매처 매칭 상품의 실제 카테고리가 일치하는가"를 판별하는 방법을 설계**한다. 코드 구현은 다음 단계 — 이번엔 **설계 문서**까지만.

### 제약 조건 (반드시 반영)
- **SE05로 네이버 쇼핑검색 카테고리 API가 영구 종료됨**(#324, 2026-07-31). 쇼핑검색으로 "이 키워드의 정상 카테고리"를 역조회하는 우회가 **불가능**하다. 이 제약 안에서 실현 가능한 방법을 찾아야 한다.
- 살아있는 API: DataLab 트렌드, 검색광고 키워드도구(경쟁지수), 도매매/도매꾹 OpenAPI(ver=4.1, 상품 목록·카테고리 코드 포함).
- **취급 제외 정책**(식품·화장품·브랜드)은 이미 `judgeExclusion()`로 처리됨 — 이 리서치 범위 아님.
- 특정 상품 하드코딩 금지(전 상품 공통, #55). 범용 규칙이어야 함.

## 3. 조사 항목 (권장 방향, 확정 아님)

Cowork가 아래를 조사·비교해 **가장 현실적인 1~2개 방안을 권장**해 주세요.

### 방안 A: 도매처 자체 카테고리 코드 활용
- 도매매/도매꾹 OpenAPI 응답에 카테고리 코드(`ca` 등)가 포함되는지 실측 확인.
- 포함된다면: 같은 키워드로 검색된 상품들의 카테고리 분포를 보고, **다수 카테고리(mode)에서 벗어난 상품을 아웃라이어로 경고**하는 방식.
- 예: "청소기" 검색 결과 대부분이 "생활가전>청소기"인데 일부가 "위생용품>귀케어"면 후자를 경고.
- 장점: 외부 API 의존 없이 도매처 응답만으로 판별. 단점: 도매처 카테고리 체계의 정밀도·일관성 확인 필요.

### 방안 B: 키워드 자체의 형태소·수식어 분석
- "귀청소기"에서 "귀"가 "청소기"를 수식하는 구조 인식 → 소싱 키워드("청소기")보다 **더 좁은 상품**임을 감지.
- 상품명이 `[수식어]+[키워드]` 패턴이고 수식어가 신체부위·용도한정어면 다른 카테고리 의심.
- 참고: 형태소 분석기(예: 은전한닢/Mecab) 없이 규칙 기반으로 가능한 범위.

### 방안 C: 대표 상품 기준 유사도
- 검색 결과 중 "가장 전형적인 본품"(예: 최다 판매·최다 등록)을 기준으로 잡고, 나머지를 그와 비교.
- 상품명 토큰 겹침·가격대 이탈로 이질 상품 감지.

### 방안 D (조합): 도매처 카테고리(A) + 가격/신호어(기존 accessoryRisk)
- 이미 구현된 priceOutlier·accessoryRisk에 카테고리 축을 더한 3중 판별.
