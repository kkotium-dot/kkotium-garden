## 2. 컬러 토큰 — 2026-09-23 재정정(대표님 2차 확인: 실제 스토어 대문 이미지 2건 근거)

**정정 경위(1차, 로고 원본 이미지 대조)**: 기존 표(레드/핑크/뉴트럴
75:15:10)는 실제 로고를 정확히 반영한 게 아니라 근사치였음을 확인.

**재정정 경위(2차, 대표님 직접 지적 + 실제 스토어 대문 2건 대조)**:
1차 정정에서 "레드+그린+블랙이 정확한 브랜드색"이라 단정한 게 성급
했음 — 대표님이 명확히 구분: **①로고 자체(워드마크+심볼) = 핑크+
레드 조합**, **②캐릭터성 디자인 활용(마케팅 비주얼·시즌 배너 등) =
레드+그린+블랙**. 이 둘은 서로 다른 용도의 서로 다른 팔레트이지
하나가 다른 하나를 대체하지 않는다. 실제 스토어 대문 이미지 2건
(여름 "Blossom in your Daily Life", 겨울 "Keep your warm daily
life") 대조로 확인: 두 이미지 모두 **레드+그린 캐릭터가 비주얼
주인공**이고, 로고 워드마크는 작게 배치(겨울 버전은 핑크 텍스트
아치+화이트 로고, 여름 버전은 화이트 텍스트+블랙 로고) — 즉 캐릭터
컬러(레드+그린)와 로고/타이포 컬러(핑크 포함)가 한 화면에서 함께
쓰이며 공존한다.

| 역할 | 이름 | HEX | 용도 |
|---|---|---|---|
| 로고 워드마크/심볼 | Brand Red | `#E62310` | 로고 자체(핑크+레드 조합 중 레드 축), CTA 버튼, 핵심 강조 |
| 로고 워드마크/심볼 | Brand Pink | `#FFCCEA`(정밀 HEX는 원본 로고파일 재확인 필요) | 로고 자체(핑크+레드 조합 중 핑크 축) — **1차 정정에서 "배경 파생색"으로 격하한 게 오류, 로고 핵심색으로 원복** |
| 캐릭터/시즌비주얼 | Brand Green | `#00A651`(스토어 대문 이미지 근사치, 정밀 HEX 재확인 필요) | 캐릭터 잎·줄기, 시즌 배너·마케팅 비주얼에서 레드와 짝을 이루는 축 — 로고 자체에는 안 쓰임 |
| 캐릭터/타이포 | Brand Black | `#000000` / `#1A1A1A` | 캐릭터 표정선, "KKOTIUM" 타이포 로고, 본문 텍스트 |
| 베이스 | Neutral White/Gray | `#FFFFFF` / `#F7F7F8` | 여백·배경. UI 화면에서는 다수 비중 |

**적용 구분 원칙(재정정)**: **UI 화면(앱 인터페이스)** — 로고 팔레트
(레드+핑크) 위주로 절제해 사용, 캐릭터 컬러(그린)는 UI 강조색으로
과용하지 않는다(원래 6월 문서의 절제 원칙은 유지). **마케팅
비주얼(썸네일·상세페이지·배너·시즌 프로모션)** — 캐릭터 팔레트
(레드+그린+블랙)를 자유롭게 활용 가능, 이게 정확히 대표님이 실제
스토어 대문에서 써오신 방식.

**보조 뉴트럴**: 본문 `#1A1A1A`, 보조 텍스트 `#6B6B6B`, 라인 `#E5E5E5`, 카드 배경 `#FAFAFA`.

**다음 세션 필수 작업**: 이 문서를 정확히 코드의 유일한 색상 기준으로
승격 — `src/app/globals.css`의 4중 변수 체계(`gp-*`/`kk-*`/
`brand-*`/`m-*`)를 이 표의 5개 역할(accent/point/wordmark/base/pink)
로 통합하는 마이그레이션이 필요(별도 작업, docs/design/
DESIGN_TOKEN_UNIFICATION_2026-09-23.md 참조).

## 3. 타이포그래피
| 레벨 | 폰트 | 크기(모바일 기준) | 용도 |
|---|---|---|---|
| 대제목 (Hero) | Pretendard Bold / 세리프(아트 무드 시) | 28~36px | 후킹 카피 |
| 섹션 제목 | Pretendard SemiBold | 22~26px | 섹션 헤더 |
| 본문 | **Pretendard Regular** | **최소 16px / 행간 1.5** | 설명 텍스트 |
| 캡션 | Pretendard Regular | 13~14px | 작품명·출처·주석 |

- **한글 본문은 Pretendard 고정**. 아트 무드가 필요한 대제목·작품 캡션은 세리프 허용(명화 갤러리 감성).
- 모바일 본문 16px 미만 금지(가독성 + 약 75~80%가 모바일).
- 이모지 사용 금지 — 아이콘은 Lucide 스타일(선형, 미니멀).

## 4. 간격·레이아웃 토큰
- **상세페이지 캔버스 폭**: 제작 1000~1200px → export 860px (네이버 권장). 모바일 우선.
- **섹션 간 여백**: 80~120px (충분한 호흡 = 아트갤러리 무드의 핵심).
- **요소 간 간격 스케일**: 8 / 16 / 24 / 40 / 64px (8의 배수).
- **카드 radius**: 16px. 버튼 radius: 12px. 이미지 radius: 12~20px.
- **CTA 버튼**: 최소 48×48px(터치 타겟), Brand Red 배경 + 화이트 텍스트, 모바일 폭 90%.
- **그림자**: 절제(아트 무드). `0 4px 20px rgba(0,0,0,0.06)` 수준.

## 5. 컴포넌트 토큰 (재사용)
- **섹션 헤더**: 라벨(핑크 배지) + 대제목 + 1줄 서브카피.
- **스펙 카드**: 화이트 배경 + 라인 보더 + Lucide 아이콘 + 라벨/값 2단.
- **신뢰 배지**: 인증·리뷰·출처표기. 핑크 또는 뉴트럴, 레드 아님(레드는 CTA 전용).
- **작품 캡션**: 작가명 · 작품명 · 제작연도 · "Public Domain" 표기 (명화 상품 진정성).
- **CTA 블록**: 대형 레드 버튼 + 짧은 초대형 카피("지금 내 차에 들이기" 류).

## 6. 카테고리별 톤 변주 (코어는 고정, 무드만 조정)
| 카테고리 | 메인 무드 | 서브 강조 | 예시 상품 |

| 아로마/방향제/디퓨저 | 아트갤러리 + 감성 | 향·지속력·차량조화 | 명화 차량용 디퓨저 |
| 전통/도어벨/소품 | 한국적 미니멀·여백 | 소재·수공·정서 | 달항아리 도어벨 |
| 주방/생활용품 | 깔끔·실용·청결감 | 기능·위생·편의 | 아이스트레이 |
