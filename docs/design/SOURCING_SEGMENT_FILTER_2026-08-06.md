# 트랙C-2 — 소싱 낙점 상태별 세그먼트 필터 설계 (2026-08-06)

> 권위 문서. 트랙C-1(SOURCING_NAKJEOM_PIPELINE) 낙점 상태관리 위에 "상태별 빠른 필터"를 얹는다.
> 상위: `docs/design/SOURCING_DEEP_DIVE_WEBAPP_2026-08-04.md` §3 트랙C.

## 1. 목표

트랙C-1로 낙점 상태(관심/소싱중/제외)를 만들었다. C-2는 **쌓인 낙점을 상태별로 빠르게 걸러 보는 것** — 발굴 키워드가 누적될수록 "지금 내가 관심 표시한 것만", "지금 진행 중인 것만" 보고 싶은 실무 니즈가 생긴다. 유료 셀러툴(셀러오션·아이템스카우트)의 소싱 관리 = 세그먼트 필터 칩 패턴.

## 2. 설계 원칙 — 요소를 늘리지 않고 기존 배지를 강화 (#274)

현재 상단 요약 배지(⭐관심 N·🌱소싱중 M)는 **표시만** 한다. 여기에 **클릭 = 필터**를 얹어 새 UI를 추가하지 않는다. 별도 필터 줄을 만들면 세로 공간을 먹고 시선이 분산된다 — 이미 있는 배지가 표시와 필터를 겸한다.

```
소싱 추천  [db-full]     [전체] [⭐관심 2] [🌱소싱중 1]     [스캔]
                          ────    ────────   ──────────
                          활성 필터 = 채워진 배경 / 비활성 = 외곽선만
```

## 3. 필터 세그먼트 정의

| 세그먼트 | 표시 조건 | 필터 결과 | 기본 |
|---|---|---|---|
| **전체** | 항상 | 제외(skipped) 뺀 전부 | ✅ 활성 |
| **⭐관심** | interestedCount>0일 때만 | operatorStatus==='interested' | |
| **🌱소싱중** | sourcingCount>0일 때만 | operatorStatus==='sourcing_started' | |

- **0건 세그먼트는 숨긴다**(노이즈 방지, 트랙C-1 요약배지 규칙 계승). 관심 0·소싱중 0이면 "전체"만 남고 필터 UI가 사실상 사라진다 → 신규 사용자에겐 복잡도 0.
- 제외(skipped)는 **필터 축이 아니다** — 별도 "제외 N건 보기" 접기로 독립 유지(트랙C-1 그대로). 제외는 "숨김"이지 "세그먼트"가 아니다.

## 4. UX 상세 (프리미엄 SaaS)

### 4-1. 필터 칩 동작
- "전체"는 항상 존재. 관심·소싱중은 카운트>0일 때만 등장.
- 클릭 시 해당 세그먼트로 목록 필터. 활성 칩은 채워진 배경(관심=노랑/소싱중=초록/전체=회색), 비활성은 외곽선.
- 단일 선택(라디오식) — 한 번에 하나의 세그먼트만. 다시 누르거나 "전체"로 해제.

### 4-2. 필터 상태에서 빈 목록 처리
- 필터 결과가 0건이면(예: 관심 필터인데 방금 마지막 관심을 해제) "전체"로 자동 폴백하지 않고, "이 조건에 해당하는 항목이 없어요" 안내 + "전체 보기" 버튼. 사용자가 왜 비었는지 알 수 있게(무음 폴백 금지, #270 정신).

### 4-3. 필터와 제외 접기의 독립성
- 필터가 무엇이든 제외 접기는 항상 하단에 독립적으로 표시(skippedCount>0일 때). 필터="관심"이어도 제외 N건 토글은 그대로.

### 4-4. 스캔 시 필터 유지
- 스캔(재조회) 후에도 현재 필터 선택을 유지한다. 단 새 스캔으로 해당 상태 항목이 사라지면 4-2 빈 목록 처리.

## 5. 구현 (전부 Desktop 단일 — 위젯 파일만)

**write set**: `src/components/dashboard/SourcingRecommendWidget.tsx` (단일 파일).
- API·훅 변경 없음 — 트랙C-1의 operatorStatus·visibleOpps 파생을 그대로 활용. **순수 클라이언트 필터**(추가 네트워크 0).
- 신규 state: `filter: 'all' | 'interested' | 'sourcing_started'` (기본 'all').
- 파생 변경: visibleOpps(제외 뺀 목록)에 filter 조건 추가 → filteredOpps.
- 상단 요약 배지를 버튼으로 승격(관심/소싱중 칩 + "전체" 칩). 클릭 시 setFilter.
- 빈 목록 안내 블록 추가.
