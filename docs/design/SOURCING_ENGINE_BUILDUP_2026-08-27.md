## 1. 엔진 목적 (대표 방향)

새싹→파워셀러 성장을 위해, **어떤 시장 변화(SEO·네이버 ROI·AI 개입)에도 "지금 소싱할 상품"을 다각도로 판단**하는 엔진. 특정 상품이 아니라 **세상을 넓게 스캔**하는 발굴 도구.

## 2. 현재 라이브 구조 (2026-08-27 기준·실측 확인)

### 2-1. 발굴 파이프라인
- **후보 발굴**: searchad 연관키워드(죽은 쇼핑검색 API 탈피, #324) → 크로스카테고리 120건급.
- **드롭십 적합도**: `dropship-fitness.ts` 감점 가중(리서치 권고 구현).
- **공급사 축**: `searchBySupplier()`(도매매 sellerId 기반) 병행.

### 2-2. 8렌즈 분류 (단일 권위 = sourcing-lenses.ts)
발굴 7렌즈 + 경고 1렌즈. 한 상품이 다중 렌즈 동시 매칭(다중 배지).

| 렌즈 | 포착 | 판정(요지) |
|---|---|---|
| 📈 급상승 | 막 뜨는 것 | trendSignal.isRising |
| 🗓️ 시즌선점 | 곧 올 성수기 | isSeasonal + 리드윈도우(1~2달 뒤) |
| 💎 니치 | 경쟁 적은 틈새+마진 | roiScore≥45 AND seo<과열 |
| 🌊 블루오션 | 수요有 경쟁低 | blueOceanScore≥70 |
| 🍯 꿀통 | 마진 우수 | roiScore≥70 |
| 🏆 황금키워드 | 검색高+마진高 | seoScore≥60 AND roiScore高 (오버레이) |
| 📚 스테디셀러 | 트렌드무관 꾸준 | trendSignal.isStable |
| ⚠️ 레드오션 | 경쟁과열 | 상위판매자 다수 → **발굴 제외·경고전용** |

### 2-3. 배분·주입 (9cf7f73 D-fix 포함)
- `assignSourcingSlots()` → `classifySourcingLenses()` 실배선(F3 해소).
- **D-fix**: `category-trend-cache`의 D1 trend를 프리페치(Set 중복제거·Promise.all·N+1 없음) 주입 → seoScore 정상화 → 🏆황금·📈급상승(SEO) 부활. (미주입 시 seoScore=50 고정으로 데드였음)
- `LENS_DAILY_QUOTA`(급상승2·시즌2·니치2·블루오션2·꿀통1·스테디1=10) 슬롯 배분.

### 2-4. 소비 표면
- **디스코드**(간단): 아침 크론 `sourcing-daily`(08:00 KST) → embed 렌즈 요약 + 레드오션 경고.
- **웹앱**(심화): /growth 소싱 위젯(트랙 A DB영속·B 상세드로어·C-1 낙점→씨앗심기 프리필·C-2 세그먼트·C-3 주간요약).
- **크론 정상**: `cron_invocation_log` 실측(매일 발화·적재).

### 2-5. 프로덕션 검증 이력
- /growth 배지 렌더 실측(인테리어=🏆황금+📚스테디). D-fix 후 황금 부활 확인.

## 3. AEO/GEO — AI 시장변화 대응 (다음 빌드업)

리서치 `NAVER_SOURCING_SEO_AEO_GEO_2026-08-20` 근거:
- 네이버는 외부 AI 크롤링 차단 → 스마트스토어는 ChatGPT/Perplexity 노출 약함. **그러나 네이버 내부 AI(브리핑·쇼핑에이전트)는 스마트스토어 상품정보·리뷰를 인용**(비중 2026.7월 27%→연말 40% 목표).
- 새싹셀러의 현실적 AI 타깃 = **네이버 내부 AI 인용** = 정확한 상품속성 입력 + 리뷰 확보.
- **엔진 확장 방향**: 소싱 추천이 "이 상품은 AEO(질문형 소제목·스펙표·FAQ) 유리한가"까지 판단 → 차별점.
