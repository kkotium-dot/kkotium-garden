# 제미나이 전달용 브리핑 — 꽃단장 작업실(Studio) 섹션별 프레임 시안 요청

작성: 2026-09-23. 목적: 제미나이가 Canvas로 "꽃단장 작업실" 섹션별
개선 프레임 코드를 제안할 때, 실제 앱 상태·확정된 디자인 시스템·
기술 제약을 정확히 반영하도록 전달하는 브리핑 원본.

---

## 1. 지금 하려는 것 — 정확한 맥락

"꽃단장 작업실"(Studio)은 네이버 스마트스토어 1인 셀러가 상품
썸네일·상세페이지를 만드는 작업 화면입니다. 기능은 많이 구현돼
있지만(4단계 워크플로우, Firefly 프롬프트 빌더, SEO 신호등 등)
레이아웃 배치가 정돈되지 않아 "구현은 많은데 제대로 못 씀" 상태입니다.
이번 대공사는 **기존 기능(로직)은 최대한 재사용**하고, **화면 배치와
디자인 톤만 프리미엄 B2B SaaS 수준으로 재설계**하는 작업입니다.

## 2. 확정된 브랜드 컬러 — 반드시 이 팔레트만 사용

**출처**: `docs/design/KKOTIUM_DESIGN_SYSTEM.md`(대표님 로고 원본

두 팔레트가 **용도별로 구분**됩니다 — 섞어 쓰지 않습니다.

|---|---|---|

| 캐릭터 팔레트 | 레드 `#E62310` + 그린 `#00A651` + 블랙 | 마케팅 비주얼(썸네일·배너·시즌 프로모션) 전용 — **이번 UI 작업에는 사용 안 함** |

**금지**: 그린/뉴브루탈 장식(하드섀도·와시테이프·회전 애니메이션)은 이전에 실험했다가 대표님 의도와 안 맞아 폐기된 방향입니다(`docs/design/archive/2026-Q3-deprecated/`) — 이번 프레임 시안에 포함하지 마세요.

## 4. 이번에 새로 필요한 것 (제미나이가 제안해줄 부분)

1. **인앱 채팅 UI** — Gemini와 대화하며 이미지 프롬프트를 다듬는
   화면(완전 신규, 배치 아이디어 필요)
2. **2x2 이미지 후보 그리드 + 대표 이미지 자동 선택** — 클릭 시
   나머지 3장은 자동으로 "추가 이미지"로 분류
3. **Adobe Firefly/Express 개입 버튼의 자연스러운 배치** — 단,
   실제로는 "클립보드 복사 + 새 창 열기" 방식(API 자동화 아님)임을
   전제로 UI를 설계할 것. 대표님이 참고용으로 제시한 3단계 예시
   (호버 시 버튼, 섹션 클릭 시 툴바)는 구조 힌트일 뿐, 실제로 "즉시
   실행되는 것처럼" 보이는 연출은 피할 것(실제로는 새 창으로
   넘어가므로)
4. **전체 레이아웃 재배치** — 현재 좌측(20%)에 핵심 작업 도구가
   눌려있고 중앙(55%, 가장 넓은 공간)이 비어있는 문제를 해결

## 5. 기술 제약 (반드시 지킬 것)

- Next.js 14 / TypeScript / React — **Tailwind 클래스가 아니라
  인라인 style 또는 CSS 변수(`var(--gp-*)` 등)를 쓰는 기존 코드
  관례**를 따를 것(제미나이의 이전 제안은 Tailwind 클래스를 썼는데,
  이 프로젝트는 Tailwind를 주력으로 안 씀 — 인라인 style 기반 코드로
  제안해주세요)
- JSX 안에 이모지 금지(Lucide React 아이콘만)
- 주석은 영어
- 다크 테마 아님 — 현재 대표님은 라이트(핑크/크림/화이트) 톤 유지를
  원하며, 다크/라이트 전환은 "정원의 낮과 밤" 컨셉으로 추후 별도
  진행 예정(이번 작업 범위 아님)

## 6. 정확히 요청하는 산출물

Studio 화면을 섹션별로 나눠(좌측 도구영역 / 중앙 작업영역 / 우측
진단영역, 그리고 그 안의 하위 구성요소별) 프레임 시안 코드를
요청합니다. 완성된 전체 페이지보다는, **섹션 단위로 나눠 각각의
배치·비율·컴포넌트 구성을 제안**해주시면 저희(Claude)가 실제 코드에
안전하게 이식하기 쉽습니다.
