# UCE-7 — 카테고리 결정론 매칭 품질 개선 설계

> 레인: Desktop(설계) · 작성 2026-08-27 · 상태: 운영자 GO 대기
> 선행: UCE-1~6(97778d2) 라이브. 이 문서는 UCE-1 결정론 매처의 **정확도** 결함만 다룬다.
> 권위: 확정 시 `category-deterministic-matcher.ts` + `category/suggest/route.ts`의 매칭 스코어링을 override.

---

## 1. 문제 (프로덕션 실측 근거, 2026-08-27 Desktop)

`/api/category/suggest`로 카탈로그 밖 임의 공산품 12종 전수 호출:

| 결과 | 상품 | 반환 | 판정 |
|---|---|---|---|
| 정확(7) | 달항아리·우산꽂이·수세미·빨래건조대·강아지목줄·블루투스스피커·제습제 | 정답 | OK |
| 오분류(4) | 실리콘주걱 | 생활/건강>공구>접착용품 | FAIL(주방용품>조리기구>주걱) |
| | 칫솔살균기 | 생활/건강>반려동물>강아지 건강관리 | FAIL |
| | 차량용방향제 | 여가/생활편의>원데이클래스>수공예 | FAIL(심각) |
| | 요가매트 | 생활/건강>반려동물>리빙용품 | FAIL |
| 빈손(1) | 스텐빨대 | n=0 | FAIL |

**정답률 58%(7/12). "존재하는 카테고리 ≠ 맞는 카테고리".**

## 2. 근본 원인 (코드 실측)

- **A. 스코어링이 부분토큰 길이 기준**: `termMatchScore`가 `name.includes(label)`이면 `label.length` 점수. '실리콘주걱'에 '실리콘'(3자·공구>접착용품>실리콘 잎) 포함 → 정답 '주걱'(2자)보다 수식어가 길어 승리. → 핵심어 아닌 수식어에 낚임.
- **B. 결정론 오답이어도 AI 교정 없음**: route.ts UCE-1 순서상 결정론이 뭐라도 반환하면 AI 미호출(usedAI:false 확정). 오답 교정 기회 없음. 원칙 #349의 부작용.
- **C. d1 정합성 게이트 부재**: 차량용방향제→여가/생활편의>원데이클래스 같은 이질 d1 매칭이 안 걸러짐.

## 3. 개선 설계 (전 상품 공통·비용0 지향)

### UCE-7a 핵심명사 가중
- `extractNouns(productName)`(구현済·복합명사 보호·조사 제거)로 핵심 명사 추출.
- label 조각이 **말단 핵심명사와 일치→강가중(×3)**, **수식어 위치→감가중(×0.5)**.
- 효과: '실리콘주걱'에서 '주걱'>'실리콘'. 구현 전 extractNouns가 '주걱' 단일 추출/복합보호하는지 케이스 단위검증(로깅).

### UCE-7b 저신뢰 결정론→AI 교정
- 결정론 최고점 임계 미만 or Tier2/3(약매칭)만 → callGroq 보조로 교차확인, usedAI:true 승격.
- AI와 결정론 불일치 시 둘 다 후보 제시→개입큐(#310 억지단일화 금지).
- 고신뢰 결정론은 AI 미호출 유지 → 비용 최소.

### UCE-7c d1 정합성 게이트
- 상품군 힌트 d1과 매칭 d1 명백 상충(서비스/레슨성 d2: 원데이클래스·예체능레슨 등) → 감점/배제.
- 서비스/레슨 카테고리는 물리상품 매칭 기본 제외목록(전 상품 공통).

### UCE-7d 빈손 시 AI 폴백
- 결정론 n=0(스텐빨대) → AI 1회 태워 후보 확보. AI도 실패 시 "카테고리 확인 필요" 개입큐(UCE-4).

## 4. 완료 조건 (검증=정확도, 존재 아님)

프로덕션 전수:
- 오분류5 정확화: 실리콘주걱→주방용품>조리기구>주걱 / 칫솔살균기→생활>욕실 or 위생가전 / 차량용방향제→자동차용품 향·디퓨저 / 요가매트→스포츠/레저 요가 / 스텐빨대→주방용품.
- 정상7 회귀0.
- AI 승격이 저신뢰에만 발동(고신뢰 usedAI:false 유지) — 로그 확인, 비용0.
- COMPLETION_GATE C1~C6 + 브라우저 씨앗심기 카테고리 제안 UI 실렌더.

## 5. 의존성·범위
- 독립. write set = category-deterministic-matcher.ts + category/suggest/route.ts(+morpheme-tokenizer 읽기전용). 소싱·8렌즈 무겹침 → 병렬 안전.
- #349 정교화(뒤엎기 아님): "저신뢰는 AI 교차확인" 단서 추가 권고.
- 전 상품 공통: 특정 상품 하드코딩 금지, 스코어링·게이트 로직 레벨만.

## 6. 개입점 (전 상품 공통)
- 결정론·AI 불일치 or 둘 다 저신뢰 → "카테고리 확인 필요" 개입큐(UCE-4) 자연 노출.
- 씨앗심기·소싱낙점·import·수동 모든 진입경로 동일 매처 경유(UCE 단일 엔진 유지).
