# F — 발행 완성축 넛지 설계 (미발행 상품 완주 유도)

> 레인: Desktop(설계) · 작성 2026-08-27 · 상태: 운영자 GO 대기
> 축 분리 원칙: 소싱=발굴축(꼬띠 추천) / **발행=완성축**(손 안의 것 마무리). 섞지 않는다.
> 재발명 금지: 기존 준비도 함수(publish-readiness.ts·upload-readiness.ts) + 발행게이트(publish-review-gate.ts) 재사용.

---

## 1. 실측 근거 (2026-08-27 Supabase)

미발행 8건(전부 DRAFT, naverProductId NULL). 문서엔 "6건"이었으나 실제 8건(문서 낡음).

| 구분 | 상품 | category_id | 판매가 | 대표이미지 | 준비도 |
|---|---|---|---|---|---|
| 거의완성(카테고리만) | 미니가습기·사무실가습기·64구아이스틀·달항아리 | **X** | O | O | 🟡 카테고리만 |
| 미착수 | 스텐빨대×2·차량용방향제 | X | X | X | 🔴 씨앗심기 필요 |

**핵심 발견**:
1. **8건 전부 category_id 빈값** → 카테고리 미연결이 공통 병목. UCE 엔진과 직결(UCE 제안 → F 넛지 자연 연결).
2. **4건은 카테고리만 채우면 즉시 발행 가능**(판매가·이미지 완비) → 새싹셀러 최속 매출 카드.
3. **중복 2쌍**(스텐빨대·64구아이스틀) → 정리 대상.
4. review_checklist 전부 NULL → 발행게이트 fail-closed(ADR-0003)라 검수 필요.

## 2. 설계 원칙

- **완성축은 발굴축(소싱봇)과 분리**: 소싱 추천에 발행넛지를 섞지 않는다(대표 지시). 발행넛지는 **대시보드 할일 + 정원창고**에만.
- **재발명 금지**: 준비도 판정은 기존 `publish-readiness`/`upload-readiness` 재사용. F는 "그 결과를 완성축 UI로 노출 + 다음 액션 유도"만.
- **전 상품 공통**: 특정 상품 하드코딩 금지. "미발행 AND 준비도<100%" 조건으로 전 상품 자동 수집.
- **개입점 자연 노출**(#56): 강제 순서 아닌, "가장 가까운 완주"를 제안.

## 3. 넛지 UI 설계

### F-1 대시보드 "완주 임박" 카드 (완성축 핵심)
- 미발행 상품을 **준비도 내림차순** 정렬 → "카테고리만 채우면 발행!" 4건을 최상단.
- 각 카드: 상품명 · 준비도 게이지 · **부족 항목 배지**(카테고리/판매가/이미지/검수) · "이어서 씨앗심기" CTA.
- 준비도 100% 근접 순 = 새싹셀러가 최소 노력으로 매출 늘리는 순서.

### F-2 정원창고 "검수 대기" 섹션 강화
- 위치축(미발행=꿀통창고) 유지하되, 준비도 배지 + "부족 1개" 같은 잔여 표시.
- UCE 카테고리 미연결 상품 → "카테고리 확인 필요"(UCE-4 개입큐)와 연동.

### F-3 완주 액션 = 씨앗심기 단일 엔진 수렴
- 어느 화면에서 CTA를 눌러도 **씨앗심기(/products/new?edit=id)** 로 이동(편집 단일 수렴 원칙).
- 부족 항목으로 **자동 포커스**(카테고리만 X면 카테고리 섹션으로 스크롤).

## 4. 로직 (재사용)

```
미발행 수집: naverProductId IS NULL
준비도 계산: 기존 calcUploadReadiness / publish-readiness 재사용
정렬: 준비도 desc (완주 임박 우선)
발행 가능 여부: assertPublishable(#311 fail-closed) 그대로
부족 항목: category_id·salePrice·mainImage·review_checklist 중 미충족
```

## 5. 완료 조건
- 대시보드에 미발행 8건이 준비도순 노출, 4건이 "카테고리만" 상단.
- CTA → 씨앗심기 편집 진입 + 부족항목 포커스 동작.
- 소싱봇/발굴축에 발행넛지 미혼입 확인(축 분리 유지).
- 브라우저 실화면 렌더 검증. COMPLETION_GATE C1~C6.

## 6. 의존성·범위
- **UCE와 시너지(의존 아님)**: 8건 전부 카테고리 공백이라 UCE 제안이 완주율을 직접 끌어올림. UCE-7 병합 후면 카테고리 제안 정확도↑ → 완주 더 쉬움. 단 F 자체는 UCE 없이도 동작(수동 카테고리 지정 가능) → 병렬 가능.
- write set: 대시보드 위젯 + 정원창고 섹션(소싱 위젯 무겹침). 소싱엔진과 병렬 안전.
- **선행 권고**: 중복 2쌍 정리(운영자 확인 후) — 넛지가 중복을 2건으로 세지 않도록.

## 7. 개입점 (전 상품 공통)
- 미발행 AND 준비도<100% → 자동으로 완주 카드 수집(상품 무관).
- 카테고리 공백 → UCE-4 개입큐와 공유(중복 큐 아님, 같은 신호 다른 표면).
