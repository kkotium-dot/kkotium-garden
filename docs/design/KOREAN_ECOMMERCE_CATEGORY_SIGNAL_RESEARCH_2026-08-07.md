# 한국어 이커머스 소싱의 카테고리 전환 동음이의어 필터링: 신호어 사전과 UX 설계 권장안

> Deep Research 산출물(2026-08-07, Desktop 요청). `KEYWORD_CATEGORY_PRECISION_2026-08-05.md` §4의 리서치 근거 원문.
> 목적: "운영자보다 전문가인 Claude가 직접 확인" 지시에 따라, 직관 초안이 아니라 실제 업계 기준(한국 소싱 SaaS 처리 방식·해외 마켓플레이스 카테고리 분류 기법·UX 표준)을 조사.

## TL;DR
- **한국의 주요 소싱/키워드 툴(아이템스카우트·셀러픽·판다랭크·셀러라이프 등)은 "동음이의 카테고리 오염"을 직접 걸러주는 전용 기능이 없다.** 이들은 키워드 단위로 "대표 카테고리"(1위 상품의 카테고리)를 표시할 뿐이며, 셀러가 엑셀로 내려받아 대표 카테고리 외 항목을 수동 삭제하는 것이 현재의 업계 표준 우회법이다. 즉 이 문제는 시장에 미해결 공백으로 남아 있고, 신규 툴/기능의 차별화 기회다.
- **가장 실무적으로 검증된 해법은 "head noun(청소기) + 수식어(귀/어항/차량용/애견)"의 접두 수식어 사전 + 카테고리 트리 매핑이다.** "청소기"는 같아도 수식어에 따라 네이버 대분류가 `디지털/가전`에서 `생활/건강(자동차용품/관상어용품/반려동물)`로 4갈래 분기하며, 이 분기를 일으키는 수식어 어휘를 신체부위·동물·장소·기기대상 등 6개 축으로 사전화하면 규칙 기반으로 높은 정밀도의 필터가 가능하다.
- **UX는 완전 배제(hard exclude)가 아니라 "경고 + 후순위 강등(demote)"이 업계 표준에 부합한다.** 오탐(false positive) 시 진짜 본품을 숨기는 비용이 크기 때문에, 확실한 케이스만 배제하고 나머지는 "다른 카테고리 의심" 배지를 달아 후순위로 내리는 신뢰도 기반 2단계(confidence-tiered) 설계를 권장한다.

## Key Findings

### 1. 문제의 본질: head noun은 같지만 수식어가 카테고리를 바꾼다
"청소기"라는 핵심 명사(head noun)는 동일하지만, 앞에 붙는 한정 수식어(modifier/premodifier)가 상품을 전혀 다른 네이버 카테고리로 보낸다. 서브에이전트 조사로 확인한 실제 네이버 쇼핑 카테고리 경로:

| 상품명 | 네이버 대분류 | 카테고리 경로(확인된 값) |
|---|---|---|
| 무선청소기/진공청소기 | 디지털/가전 | 디지털/가전 > 청소기 > 무선청소기 > 진공청소기 |
| 로봇청소기 | 디지털/가전 | 디지털/가전 > 청소기 > 로봇청소기 |
| 차량용 청소기 | 생활/건강 | 생활/건강 > 자동차용품 > 편의용품 > 차량용청소기 |
| 어항청소기 | 생활/건강 | 생활/건강 > 관상어용품 > 수조청소용품 |
| 애견 털청소기 | 생활/건강 | 생활/건강 > 반려동물 (미용/그루밍 용품군) |
| 귀청소기 | (경계 사례) | 실제로는 생활/건강·뷰티소품, 자동매칭은 가전으로 오인 |

이는 가격 이상치나 부속품 판별과 다른 축이다. 이들은 **본품(완제품)이지만 의도한 카테고리가 아닌 상품**이다. 다나와·쿠팡도 같은 분기를 보인다: 다나와는 차량용 청소기를 `자동차/용품/공구 > 세차/와이퍼/방향제`(실내세차 하위)와 `블박/충전/전자제품 > 차량용청소기`에 두고, 쿠팡은 애견 진공청소기를 "이발기/미용기/털 제거·청소용품"으로 분류한다. 즉 "청소기"라는 head noun이 있어도 그루밍 가전으로 취급된다.

### 2. 한국 소싱 툴들의 실제 처리 방식 — 전용 기능 부재
- **아이템스카우트**: "대표 카테고리" 지표를 제공한다. 이는 "네이버 쇼핑에서 검색 시 1위로 노출되는 판매상품의 카테고리"로 정의된다(아이템스쿨 위키). 그러나 이는 표시 지표일 뿐 자동 필터가 아니다. 실무 블로그(windly.cc)는 "엑셀 다운로드 후 처음 검색했던 대표 카테고리 외의 다른 카테고리는 제외하는 것이 좋다"며, 예로 '수납박스'(대표 카테고리 '생활/건강 > 수납/정리용품 > 정리함 > 소품정리함')에서 '식품 > 가루/분말류' 같은 다른 카테고리 키워드를 엑셀 필터로 수동 삭제하는 워크플로를 안내한다. 아이템스카우트가 제공하는 자동 필터는 '브랜드 제거/성별/연령대' 3종과 지표 조건 필터뿐이며, 동음이의 카테고리 전용 필터는 없다.
- **셀러픽/불사자/셀러라이프**: 카테고리 소싱, AI 키워드 추천을 제공하나 동음이의 필터는 없다. 셀러라이프 사용후기(theinfonavigator.com)는 "브랜드 상품, 아동용 제품, 통관이 안 되는 품목 등도 많이 추천… 하루 20개 추천 키워드 중 사실상 쓸 만한 키워드는 5개 내외, 많아도 10개가 되지 않았다"며 오탐 비율이 높음을 보고한다.
- **매드워드(매드파이프)**: 도매 상품대장의 상품명을 네이버 검색 API로 조회해 "각 단어별 카테고리 매칭"(상품명의 각 단어를 네이버 쇼핑에 검색해 나오는 카테고리를 일치시키는 것)을 자동화한다. 방향은 유사하나 목적이 상품명 최적화(SEO)이지 소싱 단계의 오염 제거가 아니다.
- 종합하면, 시장의 툴들은 "표시(대표 카테고리)"까지만 제공하고 "판별·배제"는 셀러의 수작업(엑셀 필터, 키워드 변형 검색)에 맡긴다. 도매매 소싱 실무 글(tojobcn.com)도 "'양말' 검색 시 양말이 아닌 것들도 검색에 잡히니 키워드를 여러 가지 붙여가며 다각도로 찾아야 한다"고 수작업 우회를 권한다.

### 3. 업계 표준 기법: 규칙 기반 사전 + 카테고리 트리 + (선택적) 임베딩
- **네이버쇼핑 자체**: 상품명을 형태소 분석 후 term 추출 → word embedding → CNN/LSTM(텍스트)과 MobileNet(이미지) 기반 자동 카테고리 매칭 모델을 운영한다(네이버 쇼핑 개발 블로그). 네이버 블로그에 따르면 "매일 2,000만 개 이상 새로 등록되는 상품을 약 5,000개에 달하는" 카테고리로 분류하며, 블로그가 밝힌 카테고리 자동 매칭 정확도는 약 85% 수준이다.
- **버즈니(홈쇼핑모아)**: 조현제 버즈니 AI Lab 팀장의 컴퓨터월드 기고(2020.07.31)에 따르면, 자체 개발 상품명 토크나이저 + TF-IDF 벡터화 + SVM으로 시작해 "텍스트 정보 추출 과정을 Bidirectional LSTM과 Self-attention 기법을 활용한 모델로 변경"했다. 규모는 1억 개 이상 상품, 체계는 3단계 기준 약 1,200개·4단계 기준 약 4,200개이며, 분류 정확도는 "3차 카테고리 기준 90% 후반, 1차 카테고리 기준으로는 100%에 가까운 정확도"로 보고된다. (홈쇼핑모아는 18개 홈쇼핑·T커머스 채널 통합 서비스, 누적 다운로드 1,500만 건 이상.)
- **아마존(글로벌 표준)**: 제품 타입 온톨로지(product type ontology)와 browse node 계층을 사용한다. 학계·산업 자료에 따르면 Q2PT(query-to-product-type) BERT 분류기로 검색어의 product type intent를 먼저 판별하고, PECOS 같은 extreme multi-label 기법으로 수천~수만 개 카테고리를 계층 트리(hierarchical label tree)로 다룬다. Product Advertising API의 SearchRefinements 리소스는 검색어에 대해 관련 browse node를 반환해 하위 카테고리로 좁히도록 하며, GetBrowseNodes로 트리를 위·아래로 탐색해 검색 범위를 일반→구체로 좁힌다.
- **Constructor 등 검색 벤더**: attribute extraction(규칙 패턴 + ML 분류기 결합), semantic vector embedding(transformer), behavioral intent scoring의 3계층을 결합한다고 공개한다. 실무 정설은 "규칙 기반 패턴 + ML 분류기의 하이브리드"다.
- **SEO 업계의 modifier 사전 관행**: 검색 의도 분류에서 "how/what/why→정보성, best/vs/review→상업성, buy/price/coupon→거래성" 같은 수식어 사전이 표준적으로 쓰인다. 동일한 "수식어→클래스" 매핑 발상을 카테고리 전환 문제에 그대로 적용할 수 있다.

**결론적 판단**: 소싱 단계의 실시간 필터에는 딥러닝 풀모델이 과하다. **접두 수식어 사전(규칙) + 네이버 카테고리 트리 매핑**이 정밀도·설명가능성·구현비용에서 가장 우수하며, 애매한 잔여 케이스만 임베딩 유사도로 보조하는 하이브리드가 최적이다. 버즈니 사례가 이를 뒷받침한다 — 1차 대분류 판별은 100%에 가까운 정확도가 나오므로, "대분류 전환" 판별은 규칙+계층 매핑만으로도 매우 신뢰할 만하다.

### 4. 카테고리 전환 한정어 사전 초안 (한국어 상품명 특화)
head noun과 결합해 카테고리를 전환시키는 수식어를 6개 의미 축으로 분류한다. 규칙: **상품명이 [축 A~F의 수식어] + [타깃 head noun] 패턴이면, 의도 카테고리와 다른 카테고리로 전환될 강한 신호**로 본다.

**축 A — 신체부위 (신체 위생/미용 소품으로 전환)**
귀, 코, 입, 눈, 손, 발, 두피, 얼굴, 치아/이, 혀, 배꼽, 발톱, 손톱, 겨드랑이 등
- 예: 귀+청소기 → 뷰티/위생소품 (가전 아님); 코+세척기; 발+각질제거기

**축 B — 동물/반려동물 (반려동물용품·관상어용품으로 전환)**
강아지, 개, 애견, 고양이, 반려, 펫, 반려동물, 애묘, 반려견, 소·대형견, 관상어/어항/수조/물고기(→관상어용품) 등
- 예: 애견/강아지/펫+털청소기 → 반려동물(미용/그루밍); 어항/수조+청소기 → 관상어용품

**축 C — 장소/이동수단 (자동차용품·특정 공간 용품으로 전환)**
차량용, 자동차, 차, 세차, 캠핑용, 낚시용, 욕실용, 주방용, 사무용, 실외/야외용, 텐트용 등
- 예: 차량용+청소기 → 자동차용품; 캠핑용+의자 → 캠핑용품

**축 D — 대상 기기/사물 (부품·전용 액세서리로 전환, 부속품 축과 경계)**
휴대폰/스마트폰, 노트북, 카메라, 안경, PC/키보드, 신발, 자전거 등
- 예: 안경+세척기; 카메라/키보드+청소기(→디지털 액세서리)
- 주의: 이 축은 "부속품 판별"과 겹치므로 사용 맥락에 따라 별도 처리 필요

**축 E — 연령/사용자 (유아·시니어 전용 카테고리로 전환)**
유아, 아기, 신생아, 아동, 어린이, 시니어, 노인, 임산부 등
- 예: 유아+세제 → 출산/육아; 아기+물티슈

**축 F — 소재/형태 축소어 (미니어처·모형·장난감으로 전환)**
미니어처, 모형, 장난감, 완구, 피규어, 인형용, 미니(맥락 의존) 등
- 예: 장난감+청소기 → 완구; 모형+자동차 → 취미

각 축의 수식어는 "화이트리스트(정상 하위 속성어)"와 반드시 구분해야 한다. 예를 들어 "무선/유선/스틱/핸디/진공/로봇/침구/차이슨" 등은 청소기의 **정상 하위 속성/브랜드**이므로 전환 신호가 아니다.

### 5. UX 패턴: 완전 배제 vs 경고+후순위
- 검색 UX 문헌(Sajari, Fact-Finder 등)은 filter(정적·하드 배제)와 facet(동적·다중선택)을 구분한다. filter는 "irrelevant results를 배제하는 hard boundary"로 정의되며 사용자가 무엇을 원하는지 명확할 때 유효하다.
- 그러나 UX 연구는 과도한 배제/제로결과가 이탈을 유발함을 시사한다. Baymard Institute의 2026년 집계(50개 연구, 최종 갱신 2025-09-22)에 따르면 평균 장바구니 이탈률은 70.22%이며, 미국 온라인 쇼핑객의 42%가 "그냥 둘러보는 중이라" 이탈한 경험이 있다고 답했다 — 즉 사용자는 조금이라도 마찰이 크면 쉽게 이탈한다. 진짜 본품을 하드 배제로 숨기는 것은 이 이탈 위험을 키운다.
- 이커머스 검색 벤더들은 순수 배제보다 relevance ranking(관련도 순위 강등)을 기본으로 하고, 확정적 필터는 사용자 선택(facet 토글)으로 노출하는 방식을 취한다.

**판단**: 소싱 툴에서 완전 자동 배제는 위험하다. 오탐 시 진짜 본품(특이한 정상 상품명, 판매자 재량 카테고리)까지 사라져 소싱 기회를 잃기 때문이다. 신뢰도 등급(confidence tier)에 따른 2단계 UX가 최적이다.

## Details

### 오탐(false positive) 최소화 실무 기준
1. **패턴 위치 규칙**: 수식어가 head noun 바로 앞(접두)에 올 때만 전환 신호로 인정. "청소기 귀 부속품"처럼 뒤에 오면 약한 신호.
2. **화이트리스트 우선**: 정상 하위 속성어(무선/유선/스틱/핸디/로봇/침구/차이슨 등 브랜드)는 전환에서 제외.
3. **경계 케이스 명시**: 서브에이전트 확인 결과 "차량용 청소기"는 판매자 재량으로 `디지털/가전 > 청소기 > 무선청소기 > 핸디청소기`에 등록되기도 한다. 즉 대분류가 판매자에 따라 갈리므로 하드 배제 금지 대상.
4. **대표 카테고리 대조**: 아이템스카우트식 "대표 카테고리"(1위 상품 카테고리)를 기준선으로 삼고, 후보 상품의 추정 카테고리가 이와 대분류 수준에서 다르면 강등.
5. **화이트/블랙 이중 사전**: 축별 수식어(블랙)와 정상 속성어(화이트)를 함께 관리해 상호 배제.

### 카테고리 트리 활용
아마존 browse node 계층 원리와 버즈니의 "1차 분류 정확도 100%에 가까움" 관찰을 차용해, **네이버 대분류(1차) 불일치는 강한 배제 신호, 중/소분류 불일치는 약한 강등 신호**로 차등 적용한다. "청소기" 검색의 기준 노드가 `디지털/가전 > 청소기`이면, 후보의 추정 대분류가 `생활/건강`이면 대분류 자체가 다르므로 높은 확신으로 강등한다. 반대로 같은 `디지털/가전 > 청소기` 안에서 무선/유선 차이는 정상 변형이므로 건드리지 않는다.

## Recommendations

**1단계 (즉시 구현, 규칙 기반)**
- 6개 축(A 신체부위, B 동물, C 장소/이동수단, D 대상기기, E 연령, F 축소어)의 접두 수식어 블랙리스트 + head noun별 정상 속성 화이트리스트를 사전으로 구축.
- 매칭 로직: `상품명이 (블랙리스트 수식어) + (검색 head noun) 패턴 && 수식어가 화이트리스트에 없음` → "카테고리 전환 의심" 플래그.
- UX: 해당 상품을 숨기지 말고 목록 하단으로 강등 + "다른 카테고리(예: 자동차용품/반려동물) 의심" 배지 표시. 사용자가 원클릭으로 "이 카테고리 제외/포함" 토글 가능하게(facet식).

**2단계 (정밀도 향상)**
- 네이버 검색 API/카테고리 매칭을 연동해 후보 상품의 실제 대표 카테고리를 조회하고, 검색 기준 카테고리와 대분류 수준 비교. 대분류 불일치만 강등, 소분류 불일치는 경고에 그침.
- 신뢰도 등급: (a) 사전+대분류 모두 불일치 → 기본 접힘(사용자가 "숨긴 항목 N개 보기"로 펼침), (b) 사전만 매칭 → 후순위 강등+배지, (c) 애매 → 정상 노출.

**3단계 (지능화, 선택)**
- 상품명 임베딩 유사도로 기준 카테고리 중심 벡터와의 거리 계산, 규칙이 놓친 신규/변칙 케이스 보조.
- 셀러 피드백(플래그 정오답)을 수집해 사전을 지속 업데이트하는 능동학습 루프 구축.

**기준 전환 임계값(threshold) — 권장안을 바꾸는 지표**
- **강등 → 하드 배제로 승격 조건**: 특정 수식어(예: "어항", "귀")의 카테고리 전환이 검증 데이터에서 대분류 기준 98% 이상(버즈니 1차 분류 정확도에 준하는 수준) 확인될 때. 그 전까지는 강등만.
- **하드 배제 → 강등으로 완화 조건**: 해당 수식어 플래그의 사용자 오탐 신고율이 임계치(예: 5%)를 넘으면 화이트리스트로 이동하거나 신뢰도 등급을 낮춤.
- **1단계 → 2단계 착수 신호**: 규칙 사전만으로 잡히지 않는 오염(수식어 없이 카테고리가 다른 케이스)이 소싱 목록의 유의미한 비율을 차지하면 API 카테고리 대조를 도입.

## Caveats
- 한국 소싱 툴들의 내부 알고리즘은 비공개이므로, "전용 필터 부재"는 공개 문서·매뉴얼·사용후기 기반 추론이다. 내부적으로 유사 기능이 있을 가능성은 완전히 배제하지 못한다.
- 네이버 카테고리 경로 중 "귀청소기"와 "애견 털청소기"의 최말단 세분류 코드는 서브에이전트가 단일 확정하지 못했다(네이버 실페이지 직접 확인 권장). 대분류 분기(디지털/가전 ↔ 생활/건강)는 확인됨.
- "차량용 청소기"처럼 판매자 재량으로 대분류가 갈리는 경계 상품이 존재하므로, 사전은 100% 결정론이 아니라 확률적 신호로 다뤄야 한다.
- 네이버 자동 카테고리 매칭 자체가 블로그 기준 약 85% 정확도로 완전하지 않으며, "귀청소기→가전 오분류", "귀이개→귀마개 오매칭" 같은 head noun 유인 오류가 실재한다. 즉 기준선(대표 카테고리)도 노이즈를 포함할 수 있으므로 2단계 API 대조도 절대적 정답은 아니다.
- Baymard 이탈률(70.22%)은 장바구니 단계 일반 통계이며 소싱 목록 UX에 1:1로 대응하는 수치는 아니다. 다만 "마찰·과도 배제가 이탈을 키운다"는 방향성의 근거로 사용했다.
- 수식어 사전은 카테고리별로 화이트/블랙 경계가 다르므로(예: "미니"는 맥락 의존, "침구"는 청소기에선 정상이지만 다른 head noun에선 전환어일 수 있음), head noun별 튜닝이 필요하다.
