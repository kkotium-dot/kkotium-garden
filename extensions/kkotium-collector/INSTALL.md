# 꽃틔움 미디어 수집기 v0.3.0 설치 안내

## 1. 압축 해제
이 ZIP 파일을 먼저 압축 해제합니다. Chrome 확장 프로그램은 ZIP 파일 자체를 바로 설치하는 방식이 아니라, 압축 해제한 폴더를 `Load unpacked`로 불러옵니다.

## 2. Chrome에 설치
1. Chrome 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드** 클릭
4. 압축 해제한 `kkotium-collector-v0.3.0` 폴더 선택
5. 확장 프로그램 목록에서 **꽃틔움 미디어 수집기** 확인
6. 퍼즐 아이콘에서 확장 프로그램을 고정하면 사용하기 편합니다.

## 3. 사용
1. 이미지/영상이 있는 웹페이지를 엽니다.
2. 툴바의 꽃틔움 미디어 수집기 아이콘을 클릭합니다.
3. Chrome 오른쪽 측면 패널에서 **현재 페이지 수집**을 클릭합니다.
4. 전체/이미지/영상 필터로 필요한 항목을 찾습니다.
5. 항목을 선택한 뒤 **선택 항목 다운로드**를 누릅니다.
6. 기본 다운로드 폴더 아래 `kkotium-collector/` 폴더에 저장됩니다.

## 4. 새로고침 문제 개선
기존 버전에서 페이지를 먼저 새로고침해야 `Receiving end does not exist` 오류가 발생하지 않는 경우가 있었습니다. v0.3.0은 수집 메시지의 수신기가 없는 경우 `content.js`를 현재 탭에 주입한 뒤 자동 재시도하도록 구성했습니다.

## 5. 다운로드가 안 되는 URL
다음 유형은 일반 `chrome.downloads.download()`로 원본 파일을 직접 저장할 수 없는 경우가 있습니다.
- `blob:` URL
- `data:` URL
- HLS `m3u8`
- DASH `mpd`
- 로그인/토큰/세션/Referer 등 추가 조건이 필요한 리소스

이 경우 수집 자체는 정상이어도 저장 단계에서 실패할 수 있으며, UI에서 `저장 불가`로 구분합니다.

## 6. 업데이트
새 버전으로 교체할 때는 기존 확장 프로그램 목록에서 **새로고침(Reload)** 하거나 기존 항목을 제거한 뒤 새 폴더를 다시 `Load unpacked`로 불러옵니다.
