# 꽃틔움 미디어 수집기 문서

> 상태: 영구
> 한 줄 요약 — 브라우저 미디어 수집기 전용 문서 진입점

이 디렉터리는 `kkotium-garden` 본 앱의 문서와 분리된
Chrome 확장프로그램 전용 문서 영역이다.

## 원칙

- 수집기 구현·설계·장애·사용법은 이 디렉터리에 기록한다.
- 본 앱의 `docs/`와 수집기 개발 문서를 혼합하지 않는다.
- 앱 기능과 수집기 기능 사이의 연동 결정만 본 앱의 ADR에서 참조한다.
- 현재 구현 상태는 실제 저장소와 브라우저 테스트 결과를 기준으로 판단한다.

## 현재 기능

- 웹페이지 이미지 수집
- 웹페이지 동영상 URL 수집
- 선택 항목 URL 복사
- 선택 항목 JSON 저장
- 선택 이미지/영상 다운로드
- 이미지/영상 필터
- 전체 선택/해제

## 알려진 제한

- `blob:` URL
- 일부 M3U8/HLS 스트리밍
- DRM 영상
- 로그인/토큰/Referer 등의 별도 접근 조건이 필요한 리소스

위 유형은 일반 `chrome.downloads.download()` 방식으로
항상 직접 파일화할 수 있는 대상이 아니다.
